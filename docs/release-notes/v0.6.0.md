GitLab gets its own place in sign-in: gitlab.com through the browser, and your own GitLab server. It needs Android 12 or later.

**Signing in through the browser, and the self-hosted GitLab, are new and have been checked in tests and against GitLab's API, not yet lived with on a phone.** If something looks wrong, please open an issue.

## Highlights

- **Sign in to gitlab.com with one tap.** "Sign in with GitLab" opens GitLab's consent page in your browser and brings you back. A personal access token still works.
- **Your own GitLab server.** Under GitLab, a switch between "gitlab.com" and "Your own server": type its address and sign in with a token. Forgeline finds out what the server runs, so picking the wrong tab doesn't matter. To sign in through the browser on your server, create an application there and paste its Application ID; the steps are in `docs/GITLAB_OAUTH_APP.md`.
- **"Other" is now "Forgejo"**, for your own Forgejo servers, so it no longer sits confusingly next to GitLab.

## Feed

- A GitLab row keeps its logo, the forge's name and the time, even when the project's name is long (`group/subgroup/project`). The repository's name shortens first, and the row takes one more line if it still doesn't fit. The same fix applies to long GitHub names.

## Known limitations

- Marking a GitLab to-do as read doesn't last (GitLab only knows pending and done).
- Label and milestone changes don't show in GitLab timelines, and the time tracker's timer can't be started there.
- Comments can't be edited, deleted or previewed, and there is no reply-with-quote.
- Issue and pull request lists stop at their first page.
- No pull request diffs yet.
- Tablets get the phone layout, centred.

No backend, no analytics, no trackers: the app talks directly to your forges. Forgeline is free software under the GPL-3.0.
