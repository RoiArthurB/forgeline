A job's log opens on its steps instead of downloading everything, Codeberg's folders and READMEs load again, and Forgeline asks the forges for less. It needs Android 12 or later.

**The step-by-step logs and the answers kept on the phone have been checked in tests and, for some forge answers, against the real APIs, but not yet lived with on a phone.** If something looks wrong, please open an issue.

## Highlights

- **Job logs, a step at a time.** A job opens on its steps, folded, with nothing of their lines read yet. An opened step shows its last 300 lines, where a failure and its summary are, and earlier lines come a window at a time when asked; the header opens the step the job failed at. A 60,000-line log used to be downloaded, parsed and listed whole, and couldn't be opened on a phone. On GitHub only the parts needed are read; Forgejo and GitLab list no steps, so their log is downloaded once and split by its own step lines.
- **Codeberg reads again.** Its folder listings took up to 31 seconds, or failed with a 504, so the Files tab, the Actions workflow list and a large repository's README could fail to load. Folders and READMEs are now read through the git tree, in one to two seconds. Pull request lists, which are slow there too, may wait up to 30 seconds before giving up.
- **Fewer requests.** A signed-in repository page asks the forge for the repository once instead of twice, and on GitHub asks whether you starred and watch it in one request. What the forges answer is also kept on the phone and checked again each time: when nothing changed, GitHub and GitLab answer without sending the data again, and GitHub doesn't count that against the rate limit. Nothing is shown without asking, so a change you just made appears at once. Signing out empties what was kept.

## Fixes

- A failed merge, review or new pull request on GitLab showed GitLab's raw answer instead of its message.
- When GitHub's hourly allowance for its GraphQL API ran out, the Inbox kept stale states without saying why; it now reports the rate limit.
- A branch name with a slash in it (`v16.0/forgejo`) pointed at the wrong path on Forgejo.
- GitLab project and file paths with unusual characters (`#`, `?`, a space) are encoded correctly.

## Known limitations

- Pictures in private repositories don't load in the code browser.
- A GitHub organisation's profile can't show social accounts: GitHub's API has none.
- An organisation's new repository in the Feed is signed by the organisation, not by the member who made it, and can take up to 30 minutes to appear.
- Discussions can't be written in yet, and a wiki opens in the browser.
- Marking a GitLab to-do as read doesn't last (GitLab only knows pending and done).
- Codeberg gives no ETag, so its answers are downloaded again each time.

No backend, no analytics, no trackers: the app talks directly to your forges. Forgeline is free software under the GPL-3.0.
