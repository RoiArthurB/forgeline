Forgeline's first release: a fast, native Android client for GitHub that opens in about a second and keeps you out of the mobile web. It needs Android 12 or later.

## Highlights

- **A new look.** Forgeline has its own design now: soft tinted headers, pill switches, rounded rows, and the Gabarito and Lexend typefaces, in light, dark and AMOLED black.
- **GitHub Actions in your pocket.** Open a run, see which job failed and at which step, read its log with colors and folded sections, jump from error to error, re-run failed jobs or cancel a run, and start a workflow by hand with its inputs.
- **Browse any branch or tag.** The README and code follow the branch or tag you pick, with every branch listed even on busy repositories.
- **Where you left off.** Trending and the Feed mark where your last visit's reading stopped.

## Inbox

- What needs you comes first (review requests, mentions, assignments, security alerts), then everything else grouped by owner and repository, with their avatars.
- Pull requests and issues say where they stand: open, draft, merged, closed or not planned.
- Swipe right to mark read, left to mark done. Every action waits 5 seconds with an **Undo**.
- Background checks (every hour by default, or off) post phone notifications on separate channels, so you can mute CI without missing mentions.
- The conversations waiting on you are loaded ahead of time, so they open instantly, even from a notification.

## Feed

- What the people you follow and the repositories you watch are doing, in strict chronological order, grouped by day.
- Each event leads with what it's about: a repository with its description, language and stars, or a pull request or issue with its state and title.
- Identical events on the same repository merge ("alice and 2 others starred"). Choose the kinds of activity you want in Settings.
- A "Where you left off" line shows where your last visit's reading stopped.

## Trending

- GitHub's trending repositories for today, this week or this month, exactly as GitHub ranks them, with owner avatars. Works without signing in.
- "Where you left off" follows the repository you stopped at even when the list reorders, and "Continue where you left off" takes you back to it.

## Repositories and code

- README rendered natively, a code browser with syntax highlighting, and issues, pull requests, releases and Actions.
- A branch and tag picker with a filter; the default branch comes first.

## GitHub Actions

- Runs show their status and duration, and each job the step it failed at.
- Job logs fold their sections (those with an error start open), keep terminal colors and highlight errors. GitHub only publishes a log once a job finishes, so a running job shows its steps live instead, then its log loads by itself.
- Signed in: re-run failed jobs or all jobs, cancel a running run, and "Run a workflow". Workflows you can start by hand are listed first, with their inputs as choices, switches or text fields.

## Conversations and profiles

- Issue and pull request timelines with reviews, merges, labels, cross-references and reactions. The title bar reads "Title - #123", and the repository above it opens in one tap.
- The last conversations you opened are kept on your phone: they show at once, even offline, while they refresh.
- User and organization profiles, with star and follow.

## Search and links

- Search repositories, issues and pull requests, and people, from every tab.
- github.com links open in the app. To turn it on: *Settings > Apps > Forgeline > Open by default > Add links*, then select `github.com`.

## Signing in

- One-tap GitHub device flow, or a classic personal access token with the `notifications`, `read:user`, `user:follow` and `public_repo` scopes.
- Logs and Actions controls need you to be signed in. Re-running, cancelling or starting a workflow also needs write access to the repository.

## Known limitations

- GitHub only for now. GitLab and Forgejo/Codeberg are on the way.
- No pull request diffs, commenting or editing yet.
- One account at a time.

No backend, no analytics, no trackers: the app talks directly to GitHub. Forgeline is free software under the GPL-3.0.
