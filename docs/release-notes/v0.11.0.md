Forgeline now reaches three more forges: Tangled, SourceHut and gitea.com, alongside GitHub, GitLab and Codeberg. Code is colored the way VS Code colors it, in every language, and in a theme of its own if you like. It needs Android 12 or later.

## Highlights

- **Tangled.** Browse Tangled's repositories, people and Trending without an account: README, files, branches and tags. Sign in with your handle and an app password to star repositories and follow people. Tangled's own Trending joins the Trending page as Tangled picked it.
- **SourceHut.** Sign in to git.sr.ht with a token and browse its repositories (README, files, branches, and tags with their notes and files) and people. Its links open in the app.
- **Gitea.** gitea.com and your own Gitea server are now opened as Gitea, not as a Forgejo, so what Gitea offers and Forgejo doesn't (re-running a run) shows up, and what it lacks (cancelling one) doesn't. gitea.com has its own place on the sign-in screen, through the browser.
- **Code colored as VS Code colors it.** The file viewer and README code blocks now use VS Code's own TextMate grammars, for every language they cover: JSON, YAML, TOML, SQL, Dockerfiles, Makefiles, Gradle and the rest no longer show plain.
- **A theme for code.** Settings › Appearance › Code theme: the same as the app (as before), always light or always dark.
- **Pull requests, after the merge.** A merged pull request's deleted branch can be restored on every forge, and on GitHub the merge can be reverted with a new pull request. Its checks are followed while they run, every 30 seconds, instead of read once.
- **Clear out the Inbox.** A row above the list counts the threads whose pull request or issue is closed or merged, and marks them all done in one tap, with one Undo.
- **Co-authors.** A commit names its co-authors beside its author, with their avatars, in commit lists, on a commit's page and in blame.
- **Repositories' own pictures.** A GitLab project or Codeberg repository shows its own avatar where it has one, instead of its owner's.
- **README links to files** open in the file viewer at their branch, instead of going nowhere.
- **Pictures in private repositories** now load, in READMEs and in the code browser.

## Fixes

- READMEs with code blocks could crash the app, most often next to pictures.
- Threads marked done came back if the app was closed before the forge answered.
- Feed rows moved under you on a refresh, and landed below "Where you left off": every forge is now read first, then the Feed changes once.
- A merged GitHub pull request read as merged and then closed; its deleted branch was left out.
- A description's lines ran together into one paragraph on GitHub and Codeberg.
- Trending lists only repositories that really moved (5 stars today, 10 this week, 20 this month), and each forge gets the same room on the mixed page.
- A release under 0.x is tagged as semantic versioning reads it there: 0.14.0 after 0.13.2 is Major.
- A Codeberg conversation failed to open when its reviews couldn't be read.
- A screen reader said "1 lines added".

## Known limitations

- Tangled: no issues, pull requests or releases yet (Tangled is moving them to a new kind of record), no CI, Feed, Inbox or search, and sign-in is by app password, not through the browser.
- SourceHut: no issues (todo.sr.ht), patches (lists.sr.ht) or builds, no Feed, Inbox or Trending, and only git.sr.ht itself, not a server of your own.
- A self-hosted Gitea signs in with a token: only gitea.com has Forgeline's application.
- A GitHub profile's activity needs you signed in to GitHub: its API only gives it to an account.
- On Codeberg, a remark on several lines or a whole file, viewed files, hidden comments, sub-issues and issue types aren't offered (Forgejo's API has none of them), a suggestion can't be committed, and a remark you take back stays.
- Marking a GitLab to-do as read doesn't last (GitLab only knows pending and done).

No backend, no analytics, no trackers: the app talks directly to your forges. Forgeline is free software under the GPL-3.0.
