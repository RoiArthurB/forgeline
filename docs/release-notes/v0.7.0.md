Writing in conversations gets much fuller: edit, delete, quote and react to comments, preview what you write, keep drafts, and attach pictures. Repositories gain watch, fork, paging, pictures you can zoom, and GitHub discussions. It needs Android 12 or later.

**The repository page's new buttons, discussions and pictures, and the picture upload on Forgejo, have been checked in tests and, for some forge answers, against real APIs, but not yet lived with on a phone.** If something looks wrong, please open an issue.

## Highlights

- **Comments, fully.** A comment's menu (the "more" button, or a long press) offers reactions, Quote reply, Edit and Delete. Double-tap a comment to give it a thumbs up, or pull it sideways to reply with a quote. A comment you rewrite opens where it stands, not at the end of the page. You can edit an issue's title and text too.
- **Preview and drafts.** Preview a comment or an issue's description before sending it. What you were writing is kept on disk until it is sent, even if the app is closed.
- **Pictures in comments** on GitLab and Forgejo, from your photo picker. GitHub has no way to upload a picture to a comment, so it isn't offered there.
- **Conversations named by number.** `#12` in a comment, a description or release notes is now a link, as are `owner/name#12` and GitLab's `!12`. Typing `#` in a comment or a new issue offers the repository's recent issues and pull requests, narrowed by number or title, with a spinner while a slow forge answers.
- **Watch and fork.** Beside Star on a repository's page. A fork asks first, then takes you to your copy. On GitLab, watching sets the project's notification level.
- **Longer lists.** Issue and pull request lists load the next page as you reach the end, and a repository's tabs show what they listed last at once while they refresh.
- **Pictures.** Image files open in the code browser, and a picture in a README, a comment or release notes opens on its own when tapped (pinch or double-tap to zoom).
- **Discussions on GitHub.** A Discussions tab on repositories that have them, and a page for each with its comments, replies and the picked answer. Reading only for now: commenting stays on GitHub's site. A discussion's link and a Feed announcement open it in the app.
- **Wiki.** A Wiki button appears where a repository has one and opens it in the browser.

## Fixes

- README badges are drawn at their real size and all as tall as each other.
- The comment box stays in sight above the keyboard.
- Errors shown in a bar (a failed delete, reaction or attachment) no longer vanish as they appear.

## Known limitations

- Pictures in private repositories don't load in the code browser.
- Discussions can't be written in yet, and a wiki has no screen of its own: [#14](https://github.com/RoiArthurB/forgeline/issues/14).
- A repository's lists are remembered until the app is closed, not longer.
- Marking a GitLab to-do as read doesn't last (GitLab only knows pending and done).
- Label and milestone changes don't show in GitLab timelines, and the time tracker's timer can't be started there.
- No pull request diffs yet.
- Tablets get the phone layout, centred.

No backend, no analytics, no trackers: the app talks directly to your forges. Forgeline is free software under the GPL-3.0.
